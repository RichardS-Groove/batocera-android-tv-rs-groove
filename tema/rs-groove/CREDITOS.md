# Tema «RS Groove» — créditos de las imágenes

vienen de dos temas del proyecto [CleanYourTV](https://github.com/Gathin23/cleanyourtv) (commit `d451b17`), con el
nombre cambiado solo por un prefijo (`anime-`, `paisaje-`).
